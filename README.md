## 🚀 Quick Start

### 1. Clone & Setup Environment:
```bash
git clone https://github.com/Eng-Ahmed-Rifai/Object-Localization-TensorFlow.git
cd Object-Localization-TensorFlow
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Launch Interactive Web Application:
```bash
streamlit run app.py
```
